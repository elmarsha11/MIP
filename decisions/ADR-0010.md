ADR-0010: Fase 3 - Descubrimiento con 20 URLs máximo, sin inventar

Fecha: 2026-08-07
Estado: Aceptado
Relacionado: ADR-0009, Fase2_Cierre.md
Contexto

Fase 2 cerró con 86 municipios únicos y Gold Standard definido. El trabajo manual que llevaba 43 horas consiste en buscar URLs oficiales para cada municipio. Necesitamos automatizarlo sin inventar URLs.
Decisión

    Fase 3 produce máximo 20 URLs candidatas por municipio, no mínimo. Si solo hay 8 reales, se guardan 8. No se fabrica.
    3 capas: heurística (0,5s) + búsqueda web (1,5min) + validación (30s).
    Cada URL debe tener: url + tipo + query fuente + fragmento título + fecha + confianza. Sin fragmento, no hay URL válida (ADR-0009).
    Tipos cerrados en enum (sitio_oficial, tramites, transparencia, salud_turnos, hacienda_tasas_rafam, reclamos_147, gde_expediente, facebook_oficial, play_store, etc).
    El POC es Navarro. Validamos contra Gold Standard que las URLs encontradas coinciden con las que usó la persona a mano.
    Criterio de cierre: investigar("Navarro") <2 min, 8-20 URLs, con al menos sitio_oficial + 1 de transparencia o trámites con confianza Alta.

Consecuencias

    Evitamos alucinación de URLs.
    Trazabilidad total desde descubrimiento.
    Base para Fase 4 (Scraping con 5 sellos) y Fase 5 (Madurez).
    Si Fase 3 falla (no encuentra sitio oficial), Fase 4 y 5 no ejecutan para ese municipio y queda como No Verificable, no como 0.

Ejemplo validado

Para Navarro:

    https://navarro.gob.ar/ - sitio_oficial - Alta - fuente: búsqueda "Municipalidad de Navarro sitio oficial" - evidencia: "Navarro tiene una nueva manera de hacer los trámites..."
    https://navarro.gob.ar/tramites-y-servicios/ - tramites - Alta - evidencia: "Tramites y Servicios – Navarro Municipalidad"

Cumple ADR-0009.
